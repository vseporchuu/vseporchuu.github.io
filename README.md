# Blockopolis Helper

Статический помощник для события Blockopolis 2026.

## Что нового в v8

- Цвета занятых клеток со скриншота сохраняются и показываются на поле только для наглядности.
- Расчёт по-прежнему не зависит от цвета блока: важны занятость клетки, линии и бомбы.
- Распознавание трёх новых фигур стало устойчивее: сначала ищется цветная область фигуры, затем проверяется заполненность ячеек каждого шаблона и уверенность распознавания.
- После сканирования показывается уверенность для каждой найденной фигуры.
- Решатель ускорен за счёт кэша мобильности и уменьшенного числа финальных кандидатов.
- Линии текущих трёх ходов остаются главным критерием.
- Среди близких вариантов учитываются свободное пространство и ограниченный прогноз будущих фигур.
- Состояние поля, цветов, фигур и настроек сохраняется после F5 через `localStorage`.
- Всё работает локально в браузере, без сервера.

## Файлы

- `index.html` — интерфейс
- `style.css` — оформление
- `script.js` — распознавание и решатель
