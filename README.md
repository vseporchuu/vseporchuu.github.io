# Blockopolis Helper v6

Локальный помощник для события «Блокополис».

## Что умеет

- Загружает скриншот поля и трёх доступных фигур.
- Распознаёт занятые клетки и бомбы без привязки к конкретному цвету блока.
- Распознаёт форму и ориентацию трёх фигур по геометрии.
- Перебирает порядок размещения всех трёх фигур.
- Ставит количество собранных линий главным критерием поиска.
- При одинаковом количестве линий предпочитает вариант с большим запасом свободного поля и доступных ходов.
- Учитывает механику бомб: первая линия через закрытую бомбу открывает её, следующая — удаляет.
- Сохраняет состояние поля, фигуры, настройки и активный слот в localStorage, поэтому после обновления страницы вводить всё заново не нужно.
- Все вычисления выполняются в браузере.

## Запуск

Открой `index.html` или размести файлы в GitHub Pages.

## Важно

Инструмент не является официальным сервисом Tanki Online.
